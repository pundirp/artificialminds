Artificial Minds · fonts

Four families side by side, one column each

Every row is the same piece of the site's own writing, set in each family's own three roles, so a row can be read straight across. The grid scrolls sideways; the family names stay at the top and the row names stay at the left.

The cross mark ✗ is in none of these faces, and the check mark ✓ is in one, Charis SIL, which is Charter's reading face; the figure row is set in the mono role, so both marks come from the reader's own device in every column here, Charter included. The arrows come from the device in the Bitter column, whose mono face has none, while Cousine and Sometype Mono carry theirs, and in every column's footer line, which is set in the label role; the manifest's marks_by_face section lists this face by face. The House column has no files at all, so it renders in whatever the machine has: here it shows the fonts of the computer or phone you opened this on.

Paragraph two

Then the guessing stops being free. Humans rank its answers, best to worst. A second system learns what they preferred, and the first one practices against it millions of times. The industry calls this reinforcement learning from human feedback. Ask any chatbot to count the letter r in strawberry and the reason it slips is in chapter one. Nothing in the practice requires anyone to know what, if anything, the mind experiences while it practices.
