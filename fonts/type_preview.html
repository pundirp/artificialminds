Type roles

The type roles for every page on the site, from 29 October 2026. Six sizes, two weights and one small-caps treatment make up eleven roles. Feeding an AI Agent the Facts is the first page on them.

fonts.css holds the three faces, and type.css holds the sizes. A page links fonts.css and carries an exact copy of type.css in its own style block. Its own CSS uses the role classes below and sets no size of its own.

The rules

  1. A page links fonts.css and carries an exact copy of type.css between the lines /* type.css begin */ and /* type.css end */.
  2. A page’s own CSS holds no size, weight, letter-spacing or small-caps value. Each rule uses a role class or a var(--t-…) value.
  3. Text in figures and buttons uses the sans. A quoted document inside a figure keeps the text face.
  4. Each SVG figure carries its scale, --u0 on a laptop and --u0p on a 390px phone, so its text lands on the role sizes.
  5. Adding a size or a role is Pundir’s decision, made once, in type.css.
